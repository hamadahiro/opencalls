Thresholds

Prize Exhibition

A Photographer's Place runs one of these monthly, and the briefs are written rather than templated — this one spends four paragraphs on what a threshold is before it gets to the file specs, which is a reasonable signal that someone is actually curating.

The hang is in Gallery X at the front of the space, which the gallery describes as its maximum-exposure wall, and the work stays on the website year-round after the show comes down. Gallery I, the bi-monthly curated space, is booked through March 2027 and is not what this call feeds.

The juror is not named yet — the page says "Juror: TBD" — so there is no roster to weigh. Jury selections are made three days after the deadline and accepted work has to be at the gallery by 4 November, which is a fast turnaround if you are shipping.

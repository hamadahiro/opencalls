Exhibition Programme 2027 — Open Call

Open call for the 2027 exhibition programme of Foto Forum in Bolzano — the South Tyrolean photography society's own gallery at Weggensteinstraße 3F, open Tuesday to Saturday with free admission, running exhibitions, photobook presentations, talks and workshops. The call is for a real exhibition slot, not a group hang: “Foto forum welcomes submissions from photographers, visual artists and other personalities working with photography”, and the organiser lists Exhibitions, Workshops and Talks/conferences as three separate submission categories with only Exhibitions carrying this deadline. NO THEME IS SET and no genre is excluded. WHAT AN EXHIBITION PROPOSAL MUST CONTAIN, verbatim from the guidelines: “8-20 images of the project (JPG)”, “Video links, if the project contains moving image work”, “Abstract of the project (PDF)”, “CV (PDF)”, “Installation proposal for our spaces (PDF)” and a “List of existing works, material, measures etc (PDF)” — so this wants a finished, installable body of work and a plan for the room, not single images. THERE IS NO ENTRY FEE: the guidelines enumerate the submission in full and never mention payment, and submission is by email to [email in contacts.json], with the organiser asking for “non-expiring file transfers with sharabke link that allows us to directly see hi-res images” and, if using Dropbox, a shared link rather than a folder invitation. NOTE THE ORGANISER'S OWN CUTOFF IS AMBIGUOUS: the page reads “Exhibitions (deadline 25th October 2026, midnight 00:00 am)”, and midnight 00:00 is the start of the 25th rather than its end, so treat 24 October as the safe date. No juror is named and no notification date is published.

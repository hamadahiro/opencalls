Temporary Storage

Prize Exhibition prize

Container Media is an indie curatorial platform. The Temporary Storage open call is for photo-based work exploring duration, process, and time as material — work that engages with photography's relationship to time rather than the photograph as a single moment.

The brief is open to photographers using photo-based practices broadly. AI-generated work is accepted.

Selected work is shown in an online photo-based exhibition.

Submission is by email with unlimited images. Application is free. Eligibility is open globally. The 2026 deadline was March 15.
